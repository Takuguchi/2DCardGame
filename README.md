# 2DCardGame

「バトルスピリッツ」のルールを再現した、Unity製の1対1ターン制2Dトレーディングカードゲームです。

一般的な2Dカードゲームのルールに加え、原作の「コア」「レベル」「ブレイブ」「マジック」といった主要システムを実装しています。

※「コア」: 青い石のような物体。コストの支払い、レベル管理、ライフに用いられる

## 主な機能

- コストを消費して手札からカードをフィールドに展開するリソース管理
- カードに『コア』を重ねることでBP（バトルポイント）が上昇する「レベル」システム（Lv1〜Lv3）
- スピリット / ブレイブ / ネクサス / マジックの4カードタイプに対応
- 既存のスピリットと合体して強化する「ブレイブ」システム
- 相手カードの破壊・ドローなど多様な効果を持つ「マジック」カード
- 対戦相手のCPU AI

## こだわった点

**『コア』のアニメーションと操作感**

原作アニメのように、コアが自動でカードに乗せられたりコストが支払われたりする演出を DOTween で実装しました。操作方法をドラッグとタップのみで完結する設計にし、カード上にコアを増やしたい時はタップするだけでコアが移動するように工夫することで、テンポ感のあるバトルを実現しています。

**汎用的なアビリティ設計と高い拡張性**

過去のカードも含めて多様なアビリティを再現することにも注力しました。原作の効果は種類が非常に多く、カード1枚ごとに専用スクリプトを書く方式では実装量が膨れ上がり、過去カードを網羅的に収録することが難しいという課題がありました。そこで ScriptableObject を用い、「対象選択」「発動条件」「効果内容」といった要素を分解し、共通のアビリティ実行ロジックの組み合わせで多様な効果を表現できる汎用的な仕組みを設計しました。結果として、新しいアビリティを持つカードを追加する際も既存ロジックの組み合わせや小さな拡張で対応できるようになり、過去カードを幅広くカバーできる拡張性を実現できました。
