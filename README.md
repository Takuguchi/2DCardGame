# 2DCardGame

「バトルスピリッツ」のルールを再現した、Unity製の1対1ターン制2Dトレーディングカードゲームです。

一般的な2Dカードゲームのルールに加え、原作の「コア」「レベル」「ブレイブ」「マジック」といった主要システムを実装しています。

## デモ

▶ [デモ動画を見る](https://youtu.be/QrpOB4RSNoU)

## 主な機能

- コストを消費して手札からカードをフィールドに展開するリソース管理
- カードに『コア』を重ねることでBP（バトルポイント）が上昇する「レベル」システム（Lv1〜Lv3）
- スピリット / ブレイブ / ネクサス / マジックの4カードタイプに対応
- 既存のスピリットと合体して強化する「ブレイブ」システム
- 相手カードの破壊・ドローなど多様な効果を持つ「マジック」カード
- 対戦相手のCPU AI

## こだわった点

**コアの配置ロジック**
1枚のカードに複数の『コア』が乗る仕様のため、当初は座標計算による独自の整列ロジック（`CoreMovement.GetRadialOffset`）を実装していましたが、UnityのGridLayoutGroupに置き換えることでコード量を削減しつつ、コアの数が変化しても崩れない安定したレイアウトを実現しました。あわせて、レイアウトグループ配下のオブジェクトをDOTweenで移動させる際に発生するレイアウト崩れを、移動中だけ親をCanvas直下へ退避させることで回避しています。

**データ駆動のカード管理**
カードごとに異なるパラメータ（コスト・BP・アビリティ等）をScriptableObject（`CardEntity`）として切り出し、Unityエディタ上でアセットとして設定・追加できるようにしました。新規カードを追加する際もコードを変更する必要がありません。

**段階的なリファクタリング**
機能追加を重ねる中で肥大化した`GameManager`クラスから責務ごとに機能を分離し、GitHub Issueでタスクを管理しながら優先度をつけて開発を進めています。
